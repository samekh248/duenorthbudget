# Metro 2

This app uses **Metro 2**, the Due North Light Panorama language.

It is the second Metro design for Due North. The first mockups were a dark
pivot with no panorama. On 2026-10-04 the chosen look became design C,
Light Panorama, and that is Metro 2 here.

This repo does not yet have budget-screen drawings. Until it does, the
reference mockups are in Due North Tasks:

`docs/design/metro-mockups.svg` in [samekh248/duenorthtasks](https://github.com/samekh248/duenorthtasks).

The rules that matter are in `.specify/memory/constitution.md` (Principles I
and II). Fluidity wins when a Metro motion would stutter.

Screen-by-screen status versus those rules (pass / partial / n/a) lives in
[metro-parity.md](metro-parity.md). That review is against Principle II and the
Tasks SVG language, not against budget artboards — this repo still has none.
